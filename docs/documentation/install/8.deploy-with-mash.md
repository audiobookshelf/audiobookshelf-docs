# Deploy with MASH (Ansible)

[MASH](https://github.com/mother-of-all-self-hosting/mash-playbook) is a community-maintained Ansible playbook that deploys self-hosted services, including Audiobookshelf, as Docker containers on your own server.

1. Set up MASH by following its [installation guide](https://github.com/mother-of-all-self-hosting/mash-playbook/blob/main/docs/README.md).
2. Enable Audiobookshelf in your `vars.yml` file as described in [MASH's Audiobookshelf documentation](https://github.com/mother-of-all-self-hosting/mash-playbook/blob/main/components/audiobookshelf/README.md).
3. Run the playbook to install it.
