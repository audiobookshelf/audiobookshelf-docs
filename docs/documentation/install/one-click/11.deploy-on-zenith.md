[Zenith](https://zenith.hosting) is one-click managed hosting for open source apps.
It runs and maintains Audiobookshelf for you, reachable at a URL with no setup.

[![Deploy with Zenith](https://cdn.zenith.hosting/buttons/deploy-with-zenith.svg)](https://zenith.hosting/host/audiobookshelf)

1. Create an account on Zenith and log in.
2. Select Audiobookshelf from the marketplace or click the link above.
3. Choose a name and region, then deploy.
4. Increase storage if needed - this is recommended for larger audiobook libraries.

:::tip
Zenith fully manages the instance, so updates, backups, and TLS are handled for you.
:::
