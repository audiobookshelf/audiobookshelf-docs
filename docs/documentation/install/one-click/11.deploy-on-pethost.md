---
title: Deploy on Pethost
sidebar_position: 1.11
---

[Pethost](https://pethost.dev) is a small cloud for personal projects, with one-click templates, nightly backups and HTTPS.

[![Deploy on Pethost](https://pethost.dev/button.svg)](https://pethost.dev/templates/audiobookshelf/)

1. Open the [Audiobookshelf template](https://pethost.dev/templates/audiobookshelf/) and click Deploy on Pethost.
2. Sign in and choose a plan, if you have no server yet.
3. Enter a password for the root user and deploy. The server is set up with it before it answers, so nobody else gets the setup page.
4. Sign in as root, create a library with the folder `/audiobooks` or `/podcasts`, and add books with the upload button.
